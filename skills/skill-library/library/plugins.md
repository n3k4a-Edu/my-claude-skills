# Other plugin skills

Plugin skills not filed under a category. Invoke with the Skill tool as `<plugin>:<skill>` when the plugin is installed.

## discord@claude-plugins-official
- **discord:access** — Manage Discord channel access — approve pairings, edit allowlists, set DM/group policy. Use when the user asks to pair, approve someone, check who's allowed, or change policy for the Discord channel.
- **discord:configure** — Set up the Discord channel — save the bot token and review access policy. Use when the user pastes a Discord bot token, asks to configure Discord, asks "how do I set this up" or "who can reach me," or wants to check…
